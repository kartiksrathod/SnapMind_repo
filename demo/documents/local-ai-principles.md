# Local AI Principles

A local-first assistant keeps document parsing, retrieval, and model execution on the user's computer whenever the installed software supports those operations.

Grounded generation means the assistant gives the language model retrieved source context and asks it to avoid unsupported claims. Citations should point to the exact source chunks used for an answer.

Privacy and performance claims must be evidence-based. A system should identify the active model, runtime, and backend, and should say when accelerator execution has not been verified.
